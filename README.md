# AI-Powered Healthcare Diagnosis Assistant

**Author: Vikas Yadav**

GitHub-ready machine-learning project based on the Wisconsin Diagnostic Breast Cancer dataset. It demonstrates preprocessing, model training, GridSearchCV tuning, evaluation, model saving, and a Streamlit interface.

> Educational/demo project only. It is not a medical device and must not be used for real-world diagnosis or treatment decisions.

## Files
- `ai_healthcare_diagnosis_assistant.ipynb` — complete notebook
- `train_model.py` — trains and saves the model
- `app.py` — Streamlit web interface
- `healthcare_diagnosis_model.joblib` — trained model
- `requirements.txt` — dependencies

## Run
```bash
pip install -r requirements.txt
python train_model.py
streamlit run app.py
```
Open the Streamlit URL in Chrome.
